Section 1 · 5 min

The Translation Layer Problem

Why this moment is different from ChatGPT

You have a research idea. Between that idea and a working result sits a translation layer: Python, R, Stata syntax, data cleaning scripts, visualisation libraries. For most economists, that layer is either a tax on productivity (if you can code) or a dependency on others (if you can't).

AI agents eliminate that translation layer. Not by making you a better programmer — by making the translation unnecessary.

💡
Key framing: We are not claiming this replaces your judgment as an economist. We are claiming it eliminates the translation layer between your idea and a working artifact.

The shift isn't that AI got smarter at text (though it did). It's that AI can now act — read your files, run code, check the output, fix errors, and iterate — all in a loop, without you touching a terminal.

Six things to understand before you start

Not technical token counts — the practical limits on your subscription. Think of it as a data plan for AI.

⚠️
There's a 7-day rolling window on some limits — if you hit a wall, it may clear sooner than you think. Set a spending cap in the Anthropic Console before using an API key.
B

Not all tasks need the smartest model. Choosing the right one saves money and time.

Extended thinking: Claude Opus can be told to "reason harder" before answering. For a standard regression, not needed. For a novel econometric design or a tricky identification strategy, worth the extra cost.
C
Context Windows

The context window is how much the model holds in memory at once — like RAM, not storage. Claude Sonnet's 200K tokens is roughly equivalent to a full PhD dissertation in a single session.

Each conversation starts fresh. If you need the agent to remember your dataset structure, your methodology choices, or prior results — that's what CLAUDE.md is for (see concept F).

⚠️
Hit "context length exceeded"? Break the task into smaller steps, or summarise prior results into CLAUDE.md so the next session starts with full context.
D
Plan Mode

By default Claude acts immediately. The --plan flag makes it show its intended steps before executing anything — like pre-registering your analysis.

bash 
claude --plan "Download the Compustat data, replicate Sloan 1996 Table 2, and flag any deviations"

Use plan mode before any operation that touches shared files, sends data somewhere, or runs code you haven't reviewed.

F
CLAUDE.md & AGENTS.md — Giving the Agent Memory

The problem: Every new conversation starts from zero. The agent doesn't know your dataset, your methodology choices, or what you tried last week.

The solution: A markdown file in your project root that the agent reads automatically at the start of every session.

CLAUDE.md Used by Claude Code
Created with claude init. Place in your project root. Claude reads it before every session.
AGENTS.md Used by OpenAI Codex CLI
Same concept, different filename. Create manually. Codex reads it at the start of every task.

Example CLAUDE.md for a finance research project:

CLAUDE.md 
# Accrual Anomaly Replication Project

## Data
- Source: WRDS / Compustat annual, 1990–2023
- Key file: data/compustat_clean.csv
- Columns: gvkey, conm, fyear, ni, at, rect, invt, dpc, oancf

## Methodology
- Replicating Sloan (1996): accrual anomaly
- Accruals = balance-sheet method (not cash-flow method)
- Winsorize at 1% and 99% before analysis

## Conventions
- Python only (no R)
- Save all output tables to results/
- Always print sample size before and after any data filter
💡
Think of CLAUDE.md as the methods section of your paper, written for an AI. If you'd explain it to a new PhD student, put it in CLAUDE.md.
Section 4 · 5 min

Setup

Get Claude Code running in under 3 minutes

Prerequisites

  • Node.js 18 or newer installed (node --version to check)
  • An Anthropic account with Claude Pro or Max subscription — or an API key
  • A terminal open (macOS: Terminal.app or iTerm; Windows: PowerShell or WSL)

Install & authenticate

bash 
npm install -g @anthropic-ai/claude-code
claude           # first run: OAuth or API key prompt
claude --version # verify install

Start a project

bash 
mkdir my-finance-project && cd my-finance-project
claude init      # creates CLAUDE.md project memory file
⚠️
API key users: Set a monthly spending limit in the Anthropic Console before running anything. $5–10 is enough for this workshop.
🚀
No install? No problem. Claude.ai with Projects (browser) covers 90% of single-session tasks. Open claude.ai, create a Project, upload your file, and use the same prompts shown below.
Section 5 · 15 min

Live Demos

Four real tasks. Download compustat_sample.csv to follow along.

📊
Demo dataset: compustat_sample.csv — 725 firm-year observations from 25 European firms, 1995–2023. Columns: gvkey, conm, fyear, ni, at, rect, invt, dpc, oancf. Structurally identical to a real WRDS/Compustat pull.
1
Clean & Explore Financial Data
4 min
bash 
claude "Load compustat_sample.csv.
Describe the data: number of firms, years covered, missing values by column.
Calculate operating accruals using the balance-sheet method:
  accruals = (change in rect + change in invt) - dpc
Normalise by lagged total assets (at).
Flag the top and bottom accrual decile for each year.
Save a summary table to accruals_summary.md"
✓
What happened: Claude read the CSV, wrote Python, ran it, handled missing values, calculated derived variables, and saved structured output — without you opening a Python file.
2
Replicate Sloan (1996) — The Accrual Anomaly
4 min
📰
Sloan (1996) showed that firms with high accruals earn lower future returns — one of the most replicated findings in accounting research. Let's reproduce the core result from Table 2 in under 4 minutes.
bash 
claude "Using compustat_sample.csv, replicate the core test from Sloan (1996).
Sort firms into accrual deciles each year.
Calculate mean next-year earnings (ni/at) for each decile.
Test whether the top and bottom decile differ significantly (t-test).
Write a paragraph describing the result in the style of a journal methods section."
✓
What happened: A published academic finding, reproduced from a plain-English description of the paper's methodology. The agent wrote the code, ran the t-test, and drafted the methods paragraph.
3
Build a Shareable Visualization
3 min
bash 
claude "Using the accrual decile results, create an HTML file with:
- A bar chart of mean future earnings (ni/at) by accrual decile
- A table showing the t-test result (t-stat, p-value, 95% CI)
Use Chart.js from a CDN. Make it clean and suitable for a conference slide."
✓
What happened: A shareable HTML artifact — ready to open in a browser, drop into a presentation, or host on GitHub Pages. ChatGPT would have given you code to paste somewhere yourself.
4
Transcribe & Structure an Earnings Call
4 min
bash 
claude "Transcribe earnings_call.m4a using the whisper command-line tool.
Then extract:
  (1) key forward-looking statements about revenue or margins
  (2) any guidance revisions (up/down vs prior quarter)
  (3) management sentiment score 1–10 with one-sentence justification
Save structured output to earnings_summary.md"
✓
What happened: Claude chained two tools — ran Whisper for speech-to-text, then applied its own reasoning to structure the transcript. An RA task that used to take half a day.

prompt 
Create a simple webpage displaying [research topic] as an interactive dashboard.

🔎 Troubleshooting common issues
  • "Not reading my file"Check you're in the right directory: run pwd and compare to where your file lives.
  • "Installed unexpected packages"Normal behaviour — Claude manages its own dependencies. Review what was installed with pip list.
  • "Running in a loop"Press Ctrl+C to interrupt. Use --plan next time to review before execution.
  • "Context length exceeded"Break the task into smaller steps, or summarise prior results into CLAUDE.md.
  • "Rate limited"You've hit the plan cooldown. Wait up to 5 hours, or switch to API access.

Take-home checklist

  • Create CLAUDE.md in every research project (claude init)
  • Use --plan before any operation that touches shared files
  • Ask Claude to explain its own code: "Walk me through what that script does"
  • Use Claude.ai Projects for cross-session memory when working in the browser
  • Set a spending cap in the Anthropic Console before using an API key
