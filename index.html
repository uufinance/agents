Section 1 · 5 min

The Translation Layer

  • You have an idea. Between that idea and a result sits a barrier.
  • Python, R, Stata — the syntax tax that slows everyone down.
  • For those who can't code: a dependency on RAs and wait times.
  • Agents eliminate that barrier entirely.
💡 We are not claiming AI replaces your judgment as an economist. We are claiming it eliminates the translation layer between your idea and a working artifact.

B · CLAUDE.md — Giving the Agent Memory

CLAUDE.md → Claude Code
Created with claude init. Place in project root. Claude reads it automatically at the start of every session.
AGENTS.md → OpenAI Codex CLI
Same concept, different filename. Create manually. Codex reads it at the start of every task.
# My Research Project

## Data
- Source: WRDS / Compustat annual, 1990–2023
- Key file: data/compustat_clean.csv
- Columns: gvkey, fyear, ni, at, rect, invt, dpc, oancf

## Methodology
- Replicating Sloan (1996): balance-sheet accrual method
- Winsorize at 1% and 99% before analysis

## Conventions
- Python only · Save all tables to results/ · Always print N before/after filters
💡 Think of CLAUDE.md as the methods section of your paper, written for an AI. If you'd explain it to a new PhD student, put it here.

C · Plan Mode

  • By default Claude acts immediately — reads your files, runs code, writes output.
  • --plan shows its intended steps before executing anything. Think of it as pre-registering your analysis.
claude --plan "Download Compustat, replicate Sloan 1996 Table 2, flag any deviations"
  • Use plan mode before any operation touching shared files or running code that modifies data.

E · Context Windows

  • The context window is how much the model holds in memory at once — like RAM, not storage.
  • Claude Sonnet: 200K tokens ≈ a full PhD dissertation in one session.
  • Each conversation starts fresh. Use CLAUDE.md to carry over project knowledge.
⚠️ Hit "context length exceeded"? Break the task into smaller steps, or summarise prior results into CLAUDE.md so the next session starts fully briefed.

Setup — Prerequisites & Safety

  • Node.js 18 or newer — check with node --version
  • Anthropic account with Claude Pro or Max — or an API key
  • A terminal open (macOS: Terminal.app · Windows: PowerShell or WSL)

↓ commands for each demo

1 Clean & Explore Financial Data

claude "Load compustat_sample.csv.
Describe the data: number of firms, years covered, missing values by column.
Calculate operating accruals = (change in rect + change in invt) - dpc.
Normalise by lagged total assets. Flag top and bottom decile per year.
Save a summary table to accruals_summary.md"
✓ Claude read the CSV, wrote Python, ran it, handled missing values, and saved structured output — without you opening a Python file.

2 Replicate Sloan (1996)

📄 Sloan (1996) showed high-accrual firms earn lower future returns — one of the most replicated findings in accounting research. 
claude "Using compustat_sample.csv, replicate the core test from Sloan (1996).
Sort firms into accrual deciles each year.
Calculate mean next-year earnings (ni/at) for each decile.
Test whether top and bottom decile differ (t-test).
Write a paragraph in journal methods-section style."
✓ A published finding reproduced from a plain-English description of the paper's methodology. The agent wrote the code, ran the test, and drafted the methods paragraph.

3 Build a Shareable Visualisation

claude "Using the accrual decile results, create an HTML file with:
- A bar chart of mean future earnings (ni/at) by accrual decile
- A table showing the t-test result (t-stat, p-value, 95% CI)
Use Chart.js from CDN. Make it clean and suitable for a conference slide."
✓ A shareable HTML artifact — open in a browser, drop into a presentation, or host on GitHub Pages. ChatGPT would have given you code to paste somewhere yourself.

4 Transcribe & Structure an Earnings Call

claude "Transcribe earnings_call.m4a using the whisper command-line tool.
Then extract:
  (1) key forward-looking statements about revenue or margins
  (2) any guidance revisions (up/down vs prior quarter)
  (3) management sentiment score 1–10 with one-sentence justification
Save structured output to earnings_summary.md"
✓ Claude chained two tools — ran Whisper for transcription, then applied reasoning to structure the output. An RA task that used to take half a day.

Troubleshooting

What you seeWhat to do
"Not reading my file"Check directory: run pwd and compare to where the file lives
"Installed unexpected packages"Normal — Claude manages dependencies. Review with pip list
"Running in a loop"Press Ctrl+C to interrupt · Use --plan next time
"Context length exceeded"Break into steps · Summarise prior work into CLAUDE.md
"Rate limited / cooldown"Wait up to 5h, or switch to API access with a token budget

Take-Home Checklist

  • Create CLAUDE.md in every research project — run claude init
  • Use --plan before any operation that touches shared files
  • Ask Claude to explain its own code: "Walk me through what that script does"
  • Use Claude.ai Projects for cross-session memory when working in the browser
